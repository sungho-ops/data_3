# IO Insight — 산업연관분석 대시보드

산업조직론 과제로 제작한 경제 데이터 분석 사이트입니다. 전국 산업연관표를 이용해 산업 간 거래, 최종수요 변화의 파급효과, 노동유발 효과와 산업구조 변화를 탐색합니다.

- [사이트 열기](https://sungho-ops.github.io/data_3/index.html)
- [확장 분석 열기](https://sungho-ops.github.io/data_3/analytics.html)

## 1. 자료 출처와 범위

자료의 입수 경로는 **통계청 → 기관별통계**이며, 통계 작성기관은 **한국은행**입니다. 사용 통계는 한국은행이 작성한 **산업연관표**입니다.

- 2022·2023·2024년 투입산출표: 생산자가격 기준 기본부문 및 통합대·중·소분류
- 2024 고용표에 함께 수록된 2022~2024년 상품 기준 취업·고용 자료
- 제공된 상품분류표: 기본부문과 통합분류 간 연결
- 분류 규모: 기본부문 380개, 소분류 165개, 중분류 83개, 대분류 33개

본 사이트는 전국표를 사용하며 지역별 분석은 제공하지 않습니다. 시트별 원자료 탐색과 산업명·코드 검색을 제공합니다. 분류는 엄밀히 상품 기준이며 화면에서는 편의상 산업이라는 표현을 함께 사용합니다.

금액은 당해년 가격의 명목값입니다. 취업·고용유발 인원은 근무시간을 전일제 근로자 기준으로 환산한 값입니다. 실제 신규 채용 인원을 의미하지는 않습니다. 노동자료는 2024 고용표의 연도별 값을 일관되게 사용하며, 과거 요약표와 혼용하지 않습니다. 거래표와 고용표의 공표 시점 차이로 개정 수준이 다를 수 있습니다.

## 2. 사용 방법

### 기본 분석

1. 분석 연도를 선택합니다.
2. **기본부문 불러오기**를 누르고 준비 완료 표시를 기다립니다. 최초 실행은 Python 실행 자원과 Excel 자료 다운로드로 시간이 걸립니다.
3. 원자료 탐색에서 **시트**를 선택합니다.
4. 행 이름이나 산업 코드를 검색하고, 행을 선택합니다. 열 검색으로 필요한 거래 상대를 찾습니다. 원표의 합계·지표 행도 포함됩니다.
5. 시뮬레이션에서 산업을 선택하고 최종수요 증가액을 **백만원** 단위로 입력하여 시나리오에 추가합니다.
6. **파급효과 계산**을 누르면 생산·수입·부가가치 유발액과 산업별 결과가 나옵니다. 여러 산업의 증가액은 합산됩니다.
7. **핵심 산업 분석하기**로 영향력·감응도 계수를 확인합니다.
8. 연도별 트렌드에서 산업을 선택하고 2022~2024년 계수를 비교합니다.

트렌드 분석은 별도 Worker에서 실행하도록 수정되어 주 분석의 데이터·시나리오·결과를 변경하지 않습니다. 수정 app.js를 배포한 이후 적용됩니다. 여러 Excel을 순차 처리하므로 기다리는 시간이 필요합니다. 초기화 버튼은 사용자가 명시적으로 현재 화면을 초기화하는 기능입니다.

### 확장 분석

왼쪽의 **확장 분석 · 6개 기능**을 누릅니다. 연도·분류·산업을 선택하고 메뉴를 이동합니다. 기본값은 2024년 대분류이며 브라우저에 저장된 선택이 있으면 복원됩니다.

| 메뉴 | 주요 기능 |
|---|---|
| 산업 한눈에 보기 | 총산출·부가가치·수입·노동 지표 요약 |
| ① 일자리 파급효과 | 증가액(억원) 입력, 직접·간접 취업 효과, 고용유발 효과, 최대 3개 산업 비교 |
| ② 수입·국산화 진단 | 수입의존도·국산화율·부가가치율 비교 |
| ③ 산업구조 변화 | 같은 코드의 2022~2024년 지표 비교 |
| ④ 소비·투자·수출 | 실제 최종수요 항목별 생산·수입·부가가치 유발액 |
| ⑤ 산업 연결 지도 | 국산 중간거래 상위 공급·수요 연결과 전체 거래표 |
| ⑥ 분류 수준 비교 | 관련 대·중·소분류 계수와 기본부문 품목 연결 |

산업 검색은 선택 분류의 코드·이름 및 연결 기본부문 품목명을 대상으로 합니다. 산업 연결 카드를 누르면 해당 산업으로 이동합니다. CSV는 현재 메뉴의 주 상세표를 저장하며, 일자리 메뉴의 보조 산업비교 표는 CSV에 포함하지 않습니다.

기본부문 노동계수는 제공되지 않아 임의로 배분하지 않습니다. 기본부문 계산은 기본 분석 화면을, 노동 분석은 대·중·소분류 화면을 이용합니다. 두 페이지의 산업·연도 선택은 자동으로 동기화되지 않습니다.

## 3. 단위

| 항목 | 단위·해석 |
|---|---|
| 기본 시뮬레이션 입력 및 원자료 금액 | 백만원 |
| 확장 일자리 분석 입력 | 억원 |
| 요약 금액 | 조원(원자료 백만원 ÷ 1,000,000) |
| 생산·수입·부가가치 유발계수 | 최종수요 1단위당 유발액 비율 |
| 영향력·감응도 계수 | 산업 평균을 1로 정규화한 무차원 계수 |
| 취업·고용계수 및 유발계수 | 최종수요 10억원당 유발 인원(명·전일제 환산) |
| 비율 | % |

1억원 = 100백만원, 10억원 = 1,000백만원입니다. 금액표의 요약 행에는 계수나 구성비가 섞일 수 있으므로 행 명칭도 확인해야 합니다. 0은 실제 0과 구분해서 사용하며, 총산출이 0이어서 비율이 정의되지 않는 경우에는 자료 없음으로 표시합니다.

## 4. 분석 방법

### 생산·수입·부가가치 유발

국산투입계수 행렬을 Ad, 수입투입계수 행렬을 Am, 부가가치율 벡터를 v, 국내 생산물의 최종수요 증가 벡터를 f라고 합니다.

- 생산유발계수 행렬: L = (I − Ad)의 역행렬
- 생산유발액: x = Lf
- 수입유발액: m = AmLf
- 부가가치유발액: va = diag(v)Lf

제공된 계수표를 사용하고 기본 분석에서는 위 행렬 관계의 잔차를 확인합니다. f는 국내 생산물 최종수요 증가로, 수입 완제품 직접 구매를 포함하지 않습니다. 여러 산업의 충격은 선형 합산되며 이번 버전은 양의 수요 증가를 입력받습니다.

### 연쇄효과

- 영향력 계수(후방): L의 해당 열 합 ÷ 전체 열 합의 평균
- 감응도 계수(전방): L의 해당 행 합 ÷ 전체 행 합의 평균
- 두 값이 모두 1 이상인 경우 화면에서 핵심산업으로 표시합니다.

이는 산업연관구조의 상대적 지표이지 기업 시장지배력이나 정책 우선순위가 아닙니다.

### 노동유발 효과

- 총 취업유발(명(전일제 환산 기준)) = 취업유발계수 × 증가액(억원) ÷ 10
- 총 고용유발(명(전일제 환산 기준)) = 고용유발계수 × 증가액(억원) ÷ 10
- 직접 취업유발 = 취업계수 × 증가액(억원) ÷ 10
- 간접 취업유발 = 총 취업유발 − 직접 취업유발

취업은 자영업자·무급가족종사자 등을 포함하고, 고용은 피용자 기준입니다. 직접 취업은 초기 최종수요에 대응한 생산의 노동투입이며, 산업 내부의 추가 파급은 간접 효과에도 포함될 수 있습니다. 산업별 유발 상세표는 제공된 취업·고용유발계수 행렬의 해당 열에 수요 증가액을 곱합니다.

### 비율과 실제 최종수요 분석

- 국산화율 = 국산 중간재 투입 / 전체 중간재 투입 × 100
- 수입의존도 = 수입 중간재 투입 / 총투입 × 100
- 부가가치율 = 부가가치 / 총투입 × 100
- 수출률 = 수출 / 총산출 × 100
- 산업 산출 구성비 = 해당 산업 총산출 / 해당 분류 전체 총산출 × 100

국산화율과 수입의존도는 분모가 달라 합이 100%가 아닙니다. 소비는 민간·정부 소비, 투자는 민간·정부 고정자본형성·재고증감·귀중품 순취득을 합칩니다. 최종수요 메뉴는 원자료의 실제 항목별 유발액을 사용하며, 임의 충격 시뮬레이션과 구분됩니다. 네트워크는 국산 중간거래로 자기 산업 거래를 포함합니다.

## 5. 해석상 한계

- 투입구조·계수가 고정된 정태적 분석입니다. 가격 조정, 생산능력 제약, 대체 투입, 정책의 인과효과를 직접 추정하지 않습니다.
- 명목 금액 증감을 실질 성장이나 생산성 향상으로 해석하지 않습니다.
- 총산출과 부가가치는 서로 다른 개념으로 합산하지 않습니다.
- 노동유발 효과는 명(전일제 환산 기준) 기준 모형 결과이며 실제 신규 채용 인원 예측이 아닙니다.
- 분류 통합 후 계산한 유발계수는 세부 계수의 단순 평균이나 합과 같지 않습니다.
- 수입의존도만으로 국가별 공급망 위험·대체 가능성을 판단하지 않습니다.
- 기업별 시장점유율 자료가 없으므로 HHI·시장집중도·기업 시장지배력을 측정하지 않습니다.

## 6. 구성과 배포

- index.html / style.css / app.js / ui.js: 기본 화면과 동작
- worker.js / model.py: 기본 분석 계산
- data/io-2022.xlsx ~ io-2024.xlsx: 기본부문 원자료
- analytics.html / analytics.css / analytics.js: 확장 화면
- analytics-data.js: 원자료에서 정리한 확장 데이터

GitHub Pages에서 저장소의 정적 파일을 배포합니다. 파일을 더블클릭한 file:// 실행은 Worker·자료 다운로드 제한으로 동작하지 않을 수 있습니다. 기본 분석은 외부 CDN에서 Python 실행 자원과 라이브러리를 내려받으므로 네트워크 연결이 필요합니다. 확장 분석은 약 12MB의 준비된 데이터 파일을 처음 불러옵니다.
